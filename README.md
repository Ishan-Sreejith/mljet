# mljet
## First LTS release of FrameForge
### The 4th version of FrameForge, featuring a more minimalistic syntax and built-in networking capabilities.

mljet is the 4th version of the FrameForge language family, with a completely redesigned syntax similar to Ruby. mljet comes with built in networking features such as opening ports, running websites locally and more. As a long-term support (LTS) version of FrameForge, it will be compatible with all future LTS versions of FrameForge by using the frwrd module available in the [Brine Cellar](https://github.com/Ishan-Sreejith/brine-cellar) repository, which contains the official modules, libraries and plugins for LTS versions of FrameForge. The mljet repository will also contain the malta compiler, updated to work with the mljet featureset.
